# Окна — часть 1 (2D хоррор-анимация)

Вертикальное видео 1080×1920, 30 fps, ~98 с. Плоская 2D-анимация в едином стиле:
главный герой — круглая голова, маленькие глаза, тёмно-синяя одежда; высокие безглазые
монстры с пастью из нескольких рядов зубов; тёмно-синяя гамма, горящий город, фонарик в подъезде.

Готовое видео: `output/okna_chast1.mp4`

## Как устроено

| Файл | Что делает |
|---|---|
| `src/engine.py` | Cairo-хелперы: фигуры, камера, тряска, свет/темнота (фонарик), зерно, виньетка, текст |
| `src/characters.py` | Герой (и другие люди), монстр (вид сбоку/анфас, открывание пасти), собака, предметы |
| `src/envs.py` | Горящий город, огонь, дым, искры, спальня, подъезд в разрезе, машины |
| `src/timeline.py` | Раскладка озвучки по времени и субтитры по словам |
| `src/scenes.py` | 29 планов, синхронизированных с конкретными словами диктора |
| `src/audio.py` | Процедурный саунд-дизайн (гул, взрывы, огонь, рык, крики, шаги с эхом, лязг арматуры) + сведение с голосом |
| `src/render.py` | Параллельный рендер кадров → H.264 → склейка → звук (loudnorm −14 LUFS) |

Тайминги слов (`audio/words.json`) получены распознаванием речи (faster-whisper small),
поэтому каждая сцена и подсветка субтитров начинаются точно на нужном слове.

## Пересборка

```bash
pip install pycairo numpy scipy pillow
mkdir -p ~/.fonts && cp fonts/*.ttf ~/.fonts && fc-cache -f
cd src
python3 audio.py          # build/mix.wav
python3 render.py 16      # output/okna_chast1.mp4
python3 stills.py shots   # контактный лист кадров в build/stills/sheet.png
```

## Часть 2

Готовое видео: `output/okna_chast2.mp4` (70 с). Начинается ровно с момента, когда герой выбегает из подъезда:
первый план использует тот же код сцены, что и финал первой части (`escape_street` в `src/scenes.py`).

| Файл | Что делает |
|---|---|
| `src/timeline2.py` | Раскладка озвучки части 2 (голос ускорен на 8% через `atempo`, тембр сохранён) и субтитры |
| `src/envs2.py` | Руины, перевёрнутая машина, туман, окраина, бункер снаружи/внутри, разрез под землёй |
| `src/scenes2.py` | 19 планов + финальный опрос А/Б |
| `src/audio2.py` | Музыка (погоня → напряжение → тишина в бункере) + шаги, дыхание, ветер, скрип металла, дверь |

```bash
cd src
python3 audio2.py          # build/ep2/mix.wav
python3 render.py 16 2     # output/okna_chast2.mp4
EP=2 python3 stills.py shots
```
